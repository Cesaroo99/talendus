## Méthode

Recherche multi-angles (3PL, entrepôt, last-mile, transport, alimentaire, nuit/soir) sur sources publiques : sites officiels, pages carrières, Jobillico, SmartRecruiters, Rippling, LinkedIn **entreprise**.

Aucune entreprise déjà présente dans le catalogue Talendus (1180 fiches `main`).

## Règle email

Un courriel n’est inscrit que s’il apparaît sur une page officielle (ou page LinkedIn **entreprise** qui le publie elle-même).  
`prenom.nom@` jamais déduit. `rh@` / `jobs@` jamais supposés.

Si 3 à 5 boîtes n’existent pas publiquement : la note dit « Seulement N emails vérifiables trouvés. »

## Volume

30 entreprises **documentées**, pas 200 lignes creuses.
